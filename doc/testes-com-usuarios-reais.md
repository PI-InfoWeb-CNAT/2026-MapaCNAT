# Relatório de Testes com Usuários Reais – Mapa CNAT

---

## 1. Introdução

Este documento apresenta os resultados dos testes de usabilidade realizados com usuários reais no sistema Web **Mapa CNAT**. O objetivo é avaliar a facilidade de uso, verificar se as funcionalidades implementadas atendem às necessidades dos usuários, identificar possíveis *bugs* e coletar sugestões de melhorias para as próximas iterações do projeto.

---

## 2. Objetivos

* Avaliar a experiência de navegação e compreensão da interface por usuários reais.
* Verificar o funcionamento das funcionalidades já implementadas.
* Identificar dificuldades de uso e possíveis erros (*bugs*).
* Levantar sugestões de melhorias para futuras versões do sistema.

## 4. Metodologia

As sessões de teste serão realizadas com o sistema em execução no navegador, em uma máquina preparada pela equipe. Cada participante receberá uma lista com tarefas específicas para executar de forma autônoma, sem auxílio direto dos integrantes. Durante o uso, a equipe observará e anotará dificuldades, falhas encontradas e comentários espontâneos. Ao final, cada participante responderá a um questionário de avaliação.

---

## 5. Tarefas Propostas

| ID | Tarefa | Instrução ao usuário | Resultado esperado |
| :--- | :--- | :--- | :--- |
| **T01** | Acessar a página inicial | Acesse o endereço do Mapa CNAT no navegador. | Carregar e visualizar corretamente a tela inicial. |
| **T02** | Encontrar a opção de explorar | Localize a opção para abrir o mapa do campus. | Identificar e acessar a funcionalidade de exploração. |
| **T03** | Explorar o mapa do campus | Navegue pelo mapa e visualize os blocos ou salas disponíveis. | Conseguir interagir com o mapa e identificar os locais. |
| **T04** | Realizar cadastro | Acesse a tela de cadastro e crie uma nova conta. | Concluir o cadastro com sucesso. |
| **T05** | Realizar login | Entre no sistema utilizando os dados cadastrados. | Autenticar-se e acessar a conta no sistema. |

---

## 6. Questionário Aplicado

Ao final das tarefas, os participantes responderão às seguintes perguntas:

1. Você conseguiu realizar todas as tarefas propostas?
2. O sistema foi fácil de utilizar?
3. Você encontrou dificuldades durante a navegação?
4. Alguma funcionalidade apresentou problemas ou comportamento inesperado?
5. As informações apresentadas na tela foram claras?
6. O que você mais gostou no sistema?
7. Quais melhorias você sugeriria para o Mapa CNAT?
8. Você utilizaria o Mapa CNAT no seu dia a dia?
