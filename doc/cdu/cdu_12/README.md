# CDU0012. Traçar rota entre pontos

- **Ator principal**: Usuário qualquer
- **Atores secundários**: Nenhum
- **Resumo**: Traça rota entre pontos no mapa
- **Pré-condição**: Usuário está na tela de interação com o mapa
- **Pós-Condição**: Uma rota é traçada de um ponto ao outro 

## Fluxo Principal
| Ações do ator | Ações do sistema |
| :-----------------: | :-----------------: | 
| 1.1 - Usuário aperta em um ponto do mapa | |  
| 1.2 - Usuário aperta em outro ponto | |  
| | 2.1 - Registra o primeiro ponto selecionado | 
| | 2.2 - Registra o segundo ponto selecionado | 
| | 2.3 - Relaciona o primeiro ponto ao segundo |
| | 2.4 - Mostra uma rota em azul de um ponto ao outro |
